# ✨ Features

- 🎬 Open almost any video instantly
- 🔊 Natural AI voice narration
- 🌍 Multiple languages supported
- 🇻🇳 Vietnamese voices
- 🇺🇸 English voices
- 🇯🇵 Japanese voices
- 🇨🇳 Chinese voices
- 🇰🇷 Korean voices
- ⏱️ Perfect subtitle synchronization
- ⏩ Accurate playback after seeking
- ⏸️ Correct narration after pause/resume
- 📝 Independent narration subtitles and display subtitles
- 💾 Automatic TTS cache
- 🚀 Lightweight and optimized for low-spec PCs
- ⌨️ Full keyboard shortcut support
- 📂 Supports external `.srt` subtitle files

# 🚀 Installation

1. Download **SubVoice_Setup.exe** from the Releases page.
2. Run the installer.
3. Follow the installation wizard.
4. Launch SubVoice from the Desktop or Start Menu.

> **Note:** Windows Defender may display a warning because the application is not digitally signed. Click **More info → Run anyway** to continue.

---

# 📖 Quick Start

1. Open a video file.
2. Load a subtitle (`.srt`) file.
3. Select your preferred AI voice.
4. Click **Play**.
5. Enjoy synchronized AI subtitle narration.

---

# 🌍 Supported Languages

SubVoice supports Microsoft Edge TTS voices, including:

- Vietnamese
- English
- Japanese
- Chinese
- Korean

and many other languages supported by Microsoft Edge TTS.

---

# 💡 Why SubVoice?

SubVoice automatically converts subtitle lines into natural AI speech and keeps narration synchronized with video playback—even after seeking, pausing, or resuming. It is designed to provide a smooth movie-watching experience while remaining lightweight and easy to use.
